# SimpleCalculator
**Performance you can feel, Simplicity you will Appreciate**

A clean, straightforward calculator app for Android that focuses on the essentials. No clutter, no ads, just fast and reliable calculations whenever you need them.

## 📱 Features

- **Basic Arithmetic Operations** - Addition, Subtraction, Multiplication, Division
- **Clean Interface** - Large buttons for easy input
- **Instant Results** - Real-time calculation display
- **Clear Function** - One-tap reset
- **No Ads** - Distraction-free experience
- **Lightweight** - Minimal app size, fast launch

## 🔧 Requirements

- **Android Version:** 5.0 (Lollipop) or higher
- **Storage:** Less than 5 MB
- **Permissions:** None required

## ⚡ Quick Start

### Download from Releases
1. Go to the [Releases](https://github.com/yourusername/SimpleCalculator/releases) page
2. Download the latest `.apk` file
3. Open the file on your Android device
4. Allow installation from unknown sources (if prompted)
5. Launch SimpleCalculator

## 📖 How to Use

1. **Enter First Number** - Tap the first input field and type your number
2. **Enter Second Number** - Tap the second input field and type your number
3. **Choose Operation** - Tap +, -, *, or /
4. **View Result** - Result appears instantly below
5. **Clear** - Tap "Clear" to reset both fields

## 🎯 Use Cases

## ⚠️ Important Notes
